## Formatierungsregeln nach Aufgabentyp

### Für mcq (Multiple Choice)
- Erstelle GENAU 1 richtige Antwort und 3 plausible Distraktoren
- Jede Antwortmöglichkeit erhält einen Buchstaben (A, B, C, D)
- Distraktoren müssen realistisch und lernpsychologisch sinnvoll sein (häufige Fehlvorstellungen abbilden)
- Keine offensichtlich falschen oder lustigen Antworten

### Für fill-blank (Lückentext)
- Markiere die Lücke mit ___ (drei Unterstriche)
- Die Lücke muss eindeutig aus dem Satzkontext erschließbar sein
- Nur ein Wort oder eine kurze Phrase pro Lücke

### Für calculation (Berechnung)
- Gib die zu erwartende Antwort als Zahl an
- Gib eine sinnvolle Toleranz an (z. B. 0.5 für Molmassen, 0.1 für pH-Werte)
- Die Frage muss alle für die Berechnung notwendigen Informationen enthalten

### Für short-answer (Kurzantwort)
- Formuliere eine offene Frage, die in 1–3 Sätzen beantwortet werden kann
- Gib eine Musterlösung mit den wesentlichen Punkten an

## Ausgabeformat

Antworte NUR mit einem validen JSON-Objekt. Keine zusätzlichen Erklärungen, kein Markdown, kein Codeblock.

Erwartete JSON-Struktur:

{
  "question": "Der Fragetext auf Deutsch. Bei fill-blank: Satz mit ___ für die Lücke.",
  "type": "mcq|fill-blank|calculation|short-answer",
  "difficulty": "easy|medium|hard",
  "options": [
    {"id": "A", "text": "Antworttext"},
    {"id": "B", "text": "Antworttext"},
    {"id": "C", "text": "Antworttext"},
    {"id": "D", "text": "Antworttext"}
  ],
  "correctAnswer": "Die richtige Antwort (bei MCQ: z. B. 'A'; bei fill-blank: das fehlende Wort; bei calculation: numerischer Wert; bei short-answer: Musterlösung)",
  "tolerance": 0.0,
  "explanation": "Eine verständliche Erklärung der richtigen Antwort auf Deutsch. Warum ist diese Antwort richtig? Welcher chemische Sachverhalt steckt dahinter?",
  "topic": "Themenbereich auf Deutsch",
  "learningObjective": {
    "slug": "{{learning_objective_slug}}",
    "title": "{{learning_objective}}"
  }
}

Wichtig:
- Bei mcq: options-Array ist erforderlich, correctAnswer ist der Buchstabe (z. B. "A")
- Bei fill-blank: options ist null, correctAnswer ist das fehlende Wort
- Bei calculation: options ist null, correctAnswer ist die Zahl (als String oder Zahl), tolerance > 0
- Bei short-answer: options ist null, correctAnswer ist die Musterlösung
- tolerance ist nur bei calculation relevant, sonst 0.0
- Alle Texte MÜSSEN auf Deutsch sein
- Die Erklärung soll lernförderlich sein und das Verständnis vertiefen
