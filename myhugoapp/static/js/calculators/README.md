# js/calculators/

Calculator modules for chemie-lernen.org. Each calculator is a self-contained JavaScript file using browser globals (no ESM/CJS).

## Core

| File                      | Purpose                                                          |
| ------------------------- | ---------------------------------------------------------------- |
| `stoichiometry.js`        | Stoichiometric calculations (moles, mass, volume, concentration) |
| `calc-equation-parser.js` | Chemical equation parser and balancer                            |
| `calc-element-lookup.js`  | Element property lookup by symbol/name                           |
| `calc-massmass.js`        | Mass-to-mass conversions                                         |
| `calc-molmol.js`          | Mole-to-mole conversions                                         |
| `calc-limiting.js`        | Limiting reagent determination                                   |
| `calc-multistep.js`       | Multi-step synthesis calculations                                |
| `calc-presets.js`         | Common substance presets (molar mass, density)                   |
| `calc-history.js`         | Calculation history tracking                                     |

## Architecture

- All calculators use browser globals (loaded via `<script>` tags)
- Shared utilities from `utils/chemistry-utils.js`: `parseFormula`, `getMolarMass`, `getElementCount`, etc.
- Calculator pages follow the `ChemistryCalculator` class pattern from `chemistry-calculator-framework.js`
- Lazy loading via `lazy-loader.js` — calculators load only on their specific routes
- Practice generators may call LiteLLM via `/api/exercises/generate`
