  - id: 'k9-001'
    type: 'multiple-choice'
    question: 'Was versteht man unter der Stoffmenge n?'
    options:
      - 'Die Anzahl der Teilchen eines Stoffes, angegeben in Mol'
      - 'Die Masse eines Stoffes in Gramm'
      - 'Das Volumen eines Stoffes in Litern'
      - 'Die Dichte eines Stoffes'
    correctAnswer: 'Die Anzahl der Teilchen eines Stoffes, angegeben in Mol'
    explanation: 'Die Stoffmenge n gibt die Anzahl der Teilchen an. 1 Mol entspricht 6,022 * 10^23 Teilchen (Avogadro-Konstante). Die Einheit der Stoffmenge ist Mol (mol).'

  - id: 'k9-002'
    type: 'multiple-choice'
    question: 'Wie berechnet man die molare Masse M eines Stoffes?'
    options:
      - 'M = Summe der Atommassen der beteiligten Elemente (in g/mol)'
      - 'M = Masse geteilt durch Volumen'
      - 'M = Anzahl der Atome mal Dichte'
      - 'M = Stoffmenge mal Temperatur'
    correctAnswer: 'M = Summe der Atommassen der beteiligten Elemente (in g/mol)'
    explanation: 'Die molare Masse M ist die Masse von 1 Mol eines Stoffes. Sie wird berechnet, indem man die Atommassen aller Atome in der Formel addiert. Einheit: g/mol.'

  - id: 'k9-003'
    type: 'multiple-choice'
    question: 'Welches Volumen nimmt 1 Mol eines idealen Gases bei Normalbedingungen (0°C, 1013 hPa) ein?'
    options:
      - '22,4 L'
      - '24,5 L'
      - '1 L'
      - '100 L'
    correctAnswer: '22,4 L'
    explanation: 'Das molare Volumen eines idealen Gases beträgt bei Normalbedingungen (0°C, 1013 hPa) 22,4 L/mol. Bei Raumtemperatur (25°C) sind es etwa 24,5 L/mol.'

  - id: 'k9-004'
    type: 'multiple-choice'
    question: 'Welche Formel berechnet die Stoffmengenkonzentration c?'
    options:
      - 'c = n / V'
      - 'c = V / n'
      - 'c = m / M'
      - 'c = n * M'
    correctAnswer: 'c = n / V'
    explanation: 'Die Stoffmengenkonzentration c berechnet sich aus Stoffmenge n pro Volumen V: c = n / V. Die Einheit ist mol/L. Beispiel: 0,1 mol/L NaOH-Lösung.'

  - id: 'k9-005'
    type: 'multiple-choice'
    question: 'Wie lautet die Reaktionsgleichung für die Knallgasreaktion?'
    options:
      - '2 H2 + O2 -> 2 H2O'
      - 'H2 + O2 -> H2O2'
      - '2 H2 + 2 O2 -> 2 H2O + O2'
      - 'H2 + 2 O2 -> 2 H2O'
    correctAnswer: '2 H2 + O2 -> 2 H2O'
    explanation: 'Die Knallgasreaktion ist die exotherme Reaktion von Wasserstoff mit Sauerstoff zu Wasser: 2 H2 + O2 -> 2 H2O. Die Reaktion läuft explosionsartig ab (Knallgasprobe).'

  - id: 'k9-006'
    type: 'multiple-choice'
    question: 'Was ist der pH-Wert einer Lösung mit [H3O+] = 10^-4 mol/L?'
    options:
      - '4'
      - '10'
      - '7'
      - '14'
    correctAnswer: '4'
    explanation: 'pH = -log10([H3O+]) = -log10(10^-4) = 4. Die Lösung ist sauer (pH < 7).'

  - id: 'k9-007'
    type: 'multiple-choice'
    question: 'Welches Gesetz besagt, dass in einer chemischen Reaktion die Masse erhalten bleibt?'
    options:
      - 'Gesetz von der Erhaltung der Masse (Lavoisier)'
      - 'Gesetz von der Erhaltung der Energie'
      - 'Gesetz von Boyle-Mariotte'
      - 'Gesetz von Avogadro'
    correctAnswer: 'Gesetz von der Erhaltung der Masse (Lavoisier)'
    explanation: 'Das Gesetz von Lavoisier (18. Jh.) besagt: In einer chemischen Reaktion ist die Summe der Massen der Edukte gleich der Summe der Massen der Produkte. Masse kann weder erschaffen noch vernichtet werden.'

  - id: 'k9-008'
    type: 'short-answer'
    question: 'Wie viel Gramm wiegt 1 Mol Wasser (H2O)? (Atommassen: H=1 u, O=16 u)'
    referenceAnswer: '18 g'
    gradingHint: 'Molare Masse von H2O: 2*1 + 16 = 18 g/mol. 1 Mol Wasser wiegt also 18 g. Der Rechenweg sollte erkennbar sein.'

  - id: 'k9-009'
    type: 'short-answer'
    question: 'Berechne die Stoffmenge von 36 g Wasser (H2O, M = 18 g/mol).'
    referenceAnswer: 'n = 2 mol'
    gradingHint: 'n = m / M = 36 g / 18 g/mol = 2 mol. Die Formel n = m/M und der Rechenweg müssen erkennbar sein.'

    type: 'short-answer'
    question: 'Welches Volumen nimmt 1 Mol Kohlenstoffdioxid (CO2) bei Normalbedingungen ein?'
    referenceAnswer: '22,4 L'
