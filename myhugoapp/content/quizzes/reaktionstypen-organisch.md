  - id: 'rto-001'
    type: 'multiple-choice'
    question: 'Welcher Reaktionstyp liegt vor, wenn ein Wasserstoffatom in einem Alkan durch ein Chloratom ersetzt wird?'
    options:
      - 'Substitution'
      - 'Addition'
      - 'Eliminierung'
      - 'Umlagerung'
    correctAnswer: 'Substitution'
    explanation: 'Bei der radikalischen Substitution (SR) wird ein Wasserstoffatom durch ein Chloratom ersetzt. Methan + Chlor -> Chlormethan + HCl ist ein typisches Beispiel.'

  - id: 'rto-002'
    type: 'multiple-choice'
    question: 'Welche Reaktion ist typisch für Alkene aufgrund ihrer Doppelbindung?'
    options:
      - 'Addition'
      - 'Substitution'
      - 'Eliminierung'
      - 'Verseifung'
    correctAnswer: 'Addition'
    explanation: 'Alkene mit ihrer Doppelbindung gehen bevorzugt Additionsreaktionen ein, z.B. die Addition von Brom (Entfärbung von Bromwasser) oder die katalytische Hydrierung zu Alkanen.'

  - id: 'rto-003'
    type: 'multiple-choice'
    question: 'Welche Reaktion ist das Gegenteil einer Addition?'
    options:
      - 'Eliminierung'
      - 'Substitution'
      - 'Polymerisation'
      - 'Kondensation'
    correctAnswer: 'Eliminierung'
    explanation: 'Die Eliminierung ist die Umkehrreaktion der Addition. Bei der Eliminierung werden Atome oder Atomgruppen unter Bildung einer Mehrfachbindung abgespalten (z.B. Dehydratisierung von Alkoholen zu Alkenen).'

  - id: 'rto-004'
    type: 'multiple-choice'
    question: 'Welche Bindung wird bei der elektrophilen Addition an ein Alken zuerst geöffnet?'
    options:
      - 'Die Pi-Bindung der Doppelbindung'
      - 'Die Sigma-Bindung der Doppelbindung'
      - 'Die C-H-Bindung'
      - 'Die Bindung des angreifenden Elektrophils'
    correctAnswer: 'Die Pi-Bindung der Doppelbindung'
    explanation: 'Die Pi-Bindung einer C=C-Doppelbindung ist schwächer als die Sigma-Bindung. Bei der elektrophilen Addition wird zuerst die Pi-Bindung geöffnet, das Elektrophil greift an, es entsteht ein Carbokation.'

  - id: 'rto-005'
    type: 'multiple-choice'
    question: 'Welcher Reaktionstyp führt zur Bildung eines Esters?'
    options:
      - 'Kondensation (Veresterung)'
      - 'Addition'
      - 'Substitution'
      - 'Pyrolyse'
    correctAnswer: 'Kondensation (Veresterung)'
    explanation: 'Die Veresterung ist eine Kondensationsreaktion: Eine Carbonsäure reagiert mit einem Alkohol unter Abspaltung von Wasser zu einem Ester. Beispiel: Essigsäure + Ethanol -> Essigsäureethylester + H2O.'

  - id: 'rto-006'
    type: 'multiple-choice'
    question: 'Was entsteht bei der Hydrierung von Ethen (C2H4)?'
    options:
      - 'Ethan (C2H6)'
      - 'Ethanol (C2H5OH)'
      - 'Ethin (C2H2)'
      - 'Ethansäure (CH3COOH)'
    correctAnswer: 'Ethan (C2H6)'
    explanation: 'Die katalytische Hydrierung von Ethen ist eine Addition von Wasserstoff an die Doppelbindung: C2H4 + H2 -> C2H6 (Ethan). Benötigt wird ein Katalysator wie Nickel, Platin oder Palladium.'

  - id: 'rto-007'
    type: 'multiple-choice'
    question: 'Welcher Reaktionstyp liegt bei der radikalischen Polymerisation von Ethen zu Polyethylen vor?'
    options:
      - 'Eine Kettenreaktion, bei der viele Ethen-Moleküle durch Addition verknüpft werden'
      - 'Eine Substitutionsreaktion an den Wasserstoffatomen'
      - 'Eine Eliminierungsreaktion unter Abspaltung von Wasser'
      - 'Eine Kondensationsreaktion unter Abspaltung von HCl'
    correctAnswer: 'Eine Kettenreaktion, bei der viele Ethen-Moleküle durch Addition verknüpft werden'
    explanation: 'Die radikalische Polymerisation ist eine Kettenreaktion mit Start-, Wachstums- und Abbruchschritt. Viele Alkene (Monomere) werden durch wiederholte Addition zur Polymerkette verknüpft.'

  - id: 'rto-008'
    type: 'short-answer'
    question: 'Welches Produkt entsteht bei der Addition von Brom (Br2) an Ethen (C2H4)?'
    referenceAnswer: '1,2-Dibromethan (C2H4Br2)'
    gradingHint: 'Die Reaktion: C2H4 + Br2 -> C2H4Br2 (1,2-Dibromethan). Die Brom-Atome lagern sich an die beiden Kohlenstoffatome der ehemaligen Doppelbindung an. Diese Reaktion dient auch zum Nachweis von Doppelbindungen (Entfärbung von Bromwasser).'

  - id: 'rto-009'
    type: 'short-answer'
    question: 'Was versteht man unter einer nucleophilen Substitution (SN1/SN2)?'
    referenceAnswer: 'Eine Reaktion, bei der ein Nucleophil ein austretendes Atom (Abgangsgruppe) an einem Kohlenstoffatom verdrängt.'
    gradingHint: 'Bei der nucleophilen Substitution greift ein nucleophiles Teilchen (z.B. OH-) ein Kohlenstoffatom an und verdrängt eine Abgangsgruppe (z.B. Halogenid). SN1 verläuft über ein Carbokation, SN2 konzertiert.'

  - id: 'rto-010'
    type: 'short-answer'
    question: 'Welche Produkte entstehen bei der Dehydratisierung von Ethanol (C2H5OH)?'
    referenceAnswer: 'Ethen (C2H4) und Wasser (H2O)'
    gradingHint: 'Die Dehydratisierung von Ethanol ist eine Eliminierungsreaktion: C2H5OH -> C2H4 + H2O. Dabei wird Wasser abgespalten und es entsteht eine Doppelbindung. Benötigt wird ein Katalysator (z.B. konz. H2SO4) und Wärme.'
