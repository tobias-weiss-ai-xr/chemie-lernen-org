# Lernziele und Kompetenzen

## Nationale Bildungsstandards

### KMK-Standards für Chemie

Die ständige Konferenz der Kultusminister (KMK) definiert nationale Bildungsstandards:

- Fachkompetenzen
- Methodenkompetenzen
- Sozialkompetenzen
- Selbstkompetenzen

## Kompetenzorientierung

### Domänenspezifische Kompetenzen

**Erkenntnisgewinnung:**
- Planung von Untersuchungen
- Durchführung von Experimenten
- Analyse von Daten

**Kommunikation:**
- Beschreibung chemischer Phänomene
- Argumentation
- Präsentation

**Bewertung:**
- Einordnung von Reaktionen
- Bewertungskriterien
- Sicherheitsaspekte

## Lehrplan-Implementierung

### Lernlandkarten

- Thema → Kompetenz → Checkpoint → Assessments

### Differenzierung

- Anpassung an verschiedene Leistungsstufen
- Föderung und Unterstützung
- Adaptieve Aufgaben
