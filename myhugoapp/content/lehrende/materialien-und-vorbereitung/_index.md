# Materialien und Vorbereitung

## Unterrichtsvorbereitung — Schritt-für-Schritt-Checkliste

### 1. Stoffanalyse (2-3 Wochen vorher)
- [ ] Fachliche Inhalte analysieren: Welche Konzepte müssen die SuS verstehen?
- [ ] Voraussetzungen prüfen: Welches Vorwissen wird benötigt? Verweis auf passende Themenbereiche auf chemie-lernen.org
- [ ] Fehlvorstellungen identifizieren: Typische Schülervorstellungen recherchieren

### 2. Didaktische Planung (1-2 Wochen vorher)
- [ ] Lernziele formulieren (kognitiv, methodisch, sozial)
- [ ] Stundenverlauf skizzieren (Einstieg → Erarbeitung → Sicherung → Reflexion)
- [ ] Methoden auswählen: Experiment, Simulation, Diskussion, Gruppenarbeit
- [ ] Differenzierung planen: Zusatzaufgaben für schnelle Lerner, Hilfestellungen für langsame Lerner

### 3. Materialerstellung (1 Woche vorher)
- [ ] Arbeitsblätter erstellen oder vorhandene anpassen
- [ ] Interaktive Rechner auf chemie-lernen.org für die Stunde auswählen
- [ ] Tafelbild/Präsentation vorbereiten
- [ ] Versuchskarten und Sicherheitsdatenblätter bereitlegen

### 4. Organisatorisches (1-2 Tage vorher)
- [ ] Geräte und Chemikalien bestellen/bereitstellen
- [ ] Technik prüfen (Beamer, Tablets, Internetzugang)
- [ ] Kopien erstellen
- [ ] Sitzordnung ggf. anpassen

## Sicherheitscheckliste für Schülerexperimente

### Vor dem Experiment
- [ ] Gefährdungsbeurteilung liegt vor
- [ ] Sicherheitsdatenblätter der Chemikalien verfügbar
- [ ] Notfallausrüstung vorhanden (Augendusche, Feuerlöscher, Erste-Hilfe-Kasten)
- [ ] Schüler wurden über Sicherheitsregeln informiert
- [ ] Schutzbrillen für alle Schüler vorhanden
- [ ] Abzug vorhanden (bei gasförmigen/toxischen Stoffen)
- [ ] Abfallbehälter für chemische Abfälle bereitgestellt

### Während des Experiments
- [ ] Schutzbrillen werden getragen
- [ ] Keine Lebensmittel/Getränke im Labor
- [ ] Lange Haare zusammengebunden
- [ ] Keine losen Kleidungsstücke (Schals, Krawatten)
- [ ] Rucksäcke und Taschen außerhalb des Arbeitsbereichs

### Nach dem Experiment
- [ ] Chemikalien fachgerecht entsorgt
- [ ] Arbeitsplatz gereinigt
- [ ] Hände gewaschen
- [ ] Geräte zurückgegeben/gereinigt

## Experimentieranleitungen

### Nachweis von Kohlenstoffdioxid

**Nachweisreaktion**: $CO_2 + Ca(OH)_2 \rightarrow CaCO_3 \downarrow + H_2O$

Kalkwasser (Calciumhydroxid-Lösung) wird durch Einleiten von Kohlenstoffdioxid trüb, da schwerlösliches Calciumcarbonat ausfällt.

**Versuch**: Atemluft durch einen Strohhalm in Kalkwasser leiten. Die Trübung zeigt $CO_2$ in der Atemluft an. Anschließend mit einem [Stöchiometrie-Rechner](/stoechiometrie-rechner/) die Stoffmengen berechnen.

### Flammenfärbung — Nachweis von Metallionen

Verschiedene Metalle färben die Brennerflamme charakteristisch:

| Ion | Flammenfarbe | Wellenlänge |
|-----|-------------|-------------|
| $Na^+$ | Gelb | 589 nm |
| $K^+$ | Violett | 768 nm |
| $Ca^{2+}$ | Ziegelrot | 622 nm |
| $Sr^{2+}$ | Karminrot | 461 nm |
| $Cu^{2+}$ | Grün | 520 nm |

| Kriterium | 1 Punkt (ungenügend) | 3 Punkte (befriedigend) | 5 Punkte (sehr gut) | Gewichtung |
|-----------|---------------------|------------------------|--------------------|------------|
| **Vorbereitung** | Keine Vorbereitung erkennbar | Grundlegende Vorbereitung | Hypothesen, Materialliste, Sicherheit | 1x |
| **Durchführung** | Unsicher, grobe Fehler | Überwiegend korrekt | Präzise, selbstständig, sicher | 2x |
| **Protokoll** | Unvollständig, unstrukturiert | Vollständig, nachvollziehbar | Übersichtlich, reflektiert, fehlerdiskutiert | 2x |
| **Ergebnis** | Falsch oder fehlend | Ansatzweise richtig | Korrekt mit sinnvoller Diskussion | 1x |
| **Teamarbeit** | Stört oder dominiert | Arbeitet mit | Kooperativ, unterstützend | 1x |
