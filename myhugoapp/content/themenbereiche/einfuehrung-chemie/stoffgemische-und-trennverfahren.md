## Arten von Stoffgemischen

| Eigenschaft | Heterogenes Gemisch                | Homogenes Gemisch             |
| ----------- | ---------------------------------- | ----------------------------- |
| Phasen      | mehrere erkennbar                  | eine Phase                    |
| Beispiel    | Sand + Wasser, Granit, Öl + Wasser | Salzwasser, Luft, Legierungen |
| Trennung    | mechanisch möglich                 | Trennverfahren nötig          |

**Homogene Gemische** nennt man auch **Lösungen**: Der gelöste Stoff (Solut) ist molekular oder ionar verteilt im Lösungsmittel (Solvens). Beispiel: $NaCl$ in Wasser — $Na^+$ und $Cl^-$ gleichmäßig verteilt.

## Trennverfahren

### Filtration

Trennt **fest** von **flüssig** durch ein Filter (Porengröße). Teilchen, die größer als die Poren sind, werden zurückgehalten.

- **Alltag:** Kaffeefilter, Teebeutel, Staubsaugerfilter
- **Labor:** Vacuumfiltration, Membranfiltration
- **Prinzip:** Größenausschluss — Teilchen > Porengöße passieren nicht

### Destillation

Nutzt unterschiedliche **Siedepunkte** zur Trennung von Flüssigkeitsgemischen. Die leichter siedende Komponente verdampft zuerst und wird kondensiert.

- **Einfache Destillation:** Trennung von zwei Flüssigkeiten mit großem Siedepunktabstand ($>25\text{ K}$)
- **Fraktionierte Destillation:** Trennung bei kleinem Siedepunktabstand über eine Kolonne mit Füllkörpern
- **Alltag:** Alkoholgewinnung (Ethanol, $S_p = 78°C$ vs. Wasser, $S_p = 100°C$), Erdölraffinerie

### Chromatographie

Trennt Stoffe durch unterschiedliche **Wanderungsgeschwindigkeit** in einer stationären Phase (Papier, Kieselgel) gegenüber einer mobilen Phase (Lösungsmittel).

- **Dünnschichtchromatographie (DC):** Trennung auf einer beschichteten Glasplatte
- **Papierchromatographie:** Trennung auf Filterpapier
- **Kenngröße:** $R_f = \frac{\text{Strecke Substanz}}{\text{Strecke Lösungsmittelfront}}$ ($0 < R_f < 1$)

### Zentrifugieren

Nutzt **Dichteunterschiede** und Fliehkraft zur Trennung. Dichtere Teilchen wandern nach außen.

- **Alltag:** Wäscheschleuder, Trennung von Sahne aus Milch
- **Medizin:** Blutzentrifuge (Trennung von Blutkörperchen und Plasma)

### Extraktion

Ein Stoff wird aus einem Gemisch mit einem geeigneten **Lösungsmittel** herausgelöst. Voraussetzung: Der Stoff löst sich besser im Extraktionsmittel als im Ausgangsgemisch.

- **Alltag:** Kaffee- oder Teeaufguss (Koffein aus Kaffeebohnen ins Wasser)
- **Labor:** Flüssig-flüssig-Extraktion im Scheidetrichter

### Magnetische Trennung

Trennt **magnetische** von **nicht-magnetischen** Feststoffen.

- **Beispiel:** Eisenfeilspäne aus Sandgemisch, Recycling von Metallen

## Welches Verfahren wählt man?

Die Wahl des Trennverfahrens hängt von den **physikalischen Eigenschaften** ab:

| Unterscheidungsmerkmal    | Trennverfahren              |
| ------------------------- | --------------------------- |
| Teilchengröße             | Filtration, Sieben          |
| Siedepunkt                | Destillation                |
| Löslichkeit               | Extraktion, Kristallisation |
| Dichte                    | Zentrifugieren, Dekantieren |
| Magnetismus               | Magnetische Trennung        |
| Wanderungsgeschwindigkeit | Chromatographie             |
| Aggregatzustand           | Sublimation (fest → gas)    |
