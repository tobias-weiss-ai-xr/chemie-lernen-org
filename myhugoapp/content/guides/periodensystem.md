# Periodensystem der Elemente im Chemieraum

In unserem 3D-Chemieraum steht ein **interaktives Periodensystem** bereit —
das Herzstück für den Chemieunterricht in virtueller Realität. So nutzen
Sie es.

## Das Periodensystem finden

Nach dem Betreten des Raumes sehen Sie das Periodensystem der Elemente.
Es ist nach **Elementgruppen** farblich sortiert und interaktiv.

## Elementgruppen im Überblick

Das Periodensystem ist in Gruppen eingeteilt, die Sie direkt anwählen
können:

| Gruppe | Beispiele |
| ------ | --------- |
| **Nichtmetalle** | Wasserstoff, Kohlenstoff, Stickstoff, Sauerstoff |
| **Edelgase** | Helium, Neon, Argon |
| **Alkalimetalle** | Lithium, Natrium, Kalium |
| **Erdalkalimetalle** | Beryllium, Magnesium, Calcium |
| **Halbmetalle** | Bor, Silizium, Germanium |
| **Halogene** | Fluor, Chlor, Brom |
| **Übergangsmetalle** | Eisen, Kupfer, Gold |
| **Metalle** | Aluminium, Zink, Blei |
| **Lanthanoide** | Cer, Neodym, Europium |
| **Actinoide** | Uran, Plutonium, Americium |

## Ein Element auswählen

1. **Klicken Sie** auf ein Element-Kachel (Desktop) oder **tippen Sie** es
   an (Mobilgerät).
2. Es öffnet sich eine Detailansicht mit:
   - **Atomdaten** (Ordnungszahl, Atommasse, Elektronenkonfiguration)
   - **Modell** (Bohr-Modell oder 3D-Darstellung)
   - **Interaktive Materialien** (z. B. Quiz oder Veranschaulichungen)
3. Schließen Sie die Ansicht wieder, um weiter zu navigieren.

## Tipps für den Unterricht

- **Gruppenweise erkunden:** Lassen Sie Lernende eine Elementgruppe nach
  der anderen durchgehen und Gemeinsamkeiten notieren.
- **Quiz-Modus:** Nutzen Sie die eingebauten Fragen, um Wissen zu festigen.
- **Gemeinsam betrachten:** Stellen Sie sich mit Ihrer Lerngruppe um ein
  Element und besprechen Sie es direkt im Raum (siehe
  [Lernräume-Konzept](/pages/lernraeume-in-hubs/)).

## Häufige Fragen

**Ich finde das Periodensystem nicht — was tun?**
Manchmal muss man sich im Raum umschauen. Nutzen Sie die Steuerung
([Steuerungs-Guide](/guides/steuerung/)), um sich zu drehen und zu
bewegen. Das Periodensystem hängt an einer Wand des Raumes.

**Kann ich die Elemente auch ohne VR nutzen?**
Ja — der Raum läuft in jedem Browser. Sie brauchen keine VR-Brille.
