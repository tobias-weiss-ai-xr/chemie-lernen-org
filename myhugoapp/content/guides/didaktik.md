# Didaktische Szenarien in Hubs-Lernräumen

Dieser Guide beschreibt bewährte Unterrichtsmuster für die Nutzung von
3D-Lernräumen im Chemieunterricht. Alle Szenarien laufen direkt in
**hubs.chemie-lernen.org** — ohne Installation.

## 1. Gemeinsames 3D-Modell

**Ablauf:** Die Lehrkraft baut ein Molekül (z. B. Ethan, Glucose, Aspirin)
aus `.glb`-Bausteinen oder lädt ein fertiges Modell. Die Klasse betritt
den Raum, dreht das Modell mit der Maus und benennt funktionelle Gruppen.

**Vorteile:**
- Alle sehen dieselbe räumliche Struktur
- Lernende können das Modell selbst drehen (entdeckendes Lernen)
- Einfach vorzubereiten — ein Modell reicht

## 2. Periodensystem-Wand

**Ablauf:** Das [interaktive Periodensystem](/guides/periodensystem/) wird
als zentrale Wand präsentiert. Beim Klick auf ein Element erscheinen
atomare Daten, ein Modell und Quiz-Fragen.

**Vorteile:**
- Perfekt für Wiederholung und Quiz
- Elementgruppen farblich unterscheidbar
- Selbstständiges Erkunden in Partnerarbeit

## 3. Reaktions-Timeline

**Ablauf:** Schritt-für-Schritt-Aufbau einer Reaktion: Edukte links,
Übergangszustand mittig, Produkte rechts. Lernende bewegen Token und
ordnen Zwischenprodukte zu.

**Vorteile:**
- Veranschaulicht Reaktionsmechanismen räumlich
- Förderung von Ordnungs- und Argumentationskompetenz
- Kollaboratives Ordnen in Kleingruppen

## 4. Labor-Szene

**Ablauf:** Nachbau eines Versuchsaufbaus (Destillation, Titration).
Lernende gehen virtuell durch den Aufbau, lesen Erklärtexte und sehen
Sicherheitshinweise.

**Vorteile:**
- Gefahrfreie Annäherung an reale Experimente
- Sicherheitsunterweisung vor dem echten Versuch
- Räumliches Verständnis von Apparaturen

## Technische Hinweise für den Unterricht

- **Vorbereitung:** Raum vorher selbst betreten und alle Medien testen
  (siehe [Erste Schritte](/guides/erste-schritte/)).
- **Browser:** Chrome/Edge auf Desktop empfohlen; für ältere Geräte den
  einfachen Modus wählen.
- **Audio:** Sprachchat nur bei Bedarf aktivieren, um Hintergrundgeräusche
  zu vermeiden ([Audio-Guide](/guides/audio/)).
- **Zeit:** Planen Sie 5–10 Minuten Einarbeitung ein.
