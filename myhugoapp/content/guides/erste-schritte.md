# Erste Schritte im Chemieraum

Dieser Guide zeigt Ihnen, wie Sie einen 3D-Lernraum auf
**hubs.chemie-lernen.org** betreten und sich zurechtfinden. Für eine
Lehrkraft oder Lernende reicht ein moderner Browser — keine Installation,
kein Account erforderlich.

## 1. Raum-Link öffnen

Sie haben von Ihrer Lehrkraft oder einem Kollegen einen Link erhalten,
zum Beispiel:

```
https://hubs.chemie-lernen.org/iZER9XU/knowledgeable-great-tract
```

Öffnen Sie den Link in **Chrome, Firefox, Edge oder Safari** (Desktop oder
Mobilgerät). Die Raum-Seite lädt und zeigt den Namen des Raumes sowie
Hinweise zum Betreten.

> **Hinweis:** Verwenden Sie einen aktuellen Browser. Für die beste
> Erfahrung empfehlen wir Chrome oder Edge auf dem Desktop sowie einen
> Kopfhörer für den Sprachchat.

## 2. Name wählen und Raum betreten

1. Klicken Sie auf **"Betreten des Raums"** (bzw. den grünen Button).
2. Geben Sie Ihren **Namen** ein (oder wählen Sie einen Gast-Avatar).
3. Klicken Sie erneut auf den Button — die 3D-Szene lädt.

Sie erscheinen nun mit Ihrem Avatar im Raum. Falls Sie ein Mikrofon
erlauben, wird Ihr Sprachchat automatisch aktiviert.

## 3. Erste Bewegungen

| Aktion | Desktop | Mobil/VR |
| ------ | ------- | -------- |
| **Umsehen** | Maus bewegen | Finger ziehen / Blick |
| **Bewegen** | `W A S D` oder Pfeiltasten | Joystick |
| **Schneller bewegen** | `Shift` gedrückt halten | — |
| **Springen** | Leertaste | Doppeltipp |
| **Mit Objekten interagieren** | Klick | Tippen |

## 4. Worauf Sie im Chemieraum treffen

- **Periodensystem der Elemente:** Klicken Sie ein Element an, um
  Informationen, Modelle und interaktive Materialien zu öffnen.
- **3D-Molekülmodelle:** Drehen und skalieren Sie Modelle mit der Maus
  (siehe [Steuerung](/guides/steuerung/)).
- **Notiz-Wände & Medien:** Bilder, PDFs und Videos können an Wänden
  angeheftet sein — klicken Sie sie an, um sie zu vergrößern.

## 5. Audio & Sprachchat

- Klicken Sie auf das **Mikrofon-Symbol** unten in der Mitte, um das
  Mikrofon zu stummschalten bzw. zu aktivieren.
- Über die **Audio-Einstellungen** (Zahnrad) wählen Sie Ihr Mikrofon und
  Ihre Lautsprecher aus.
- Bei Problemen hilft der [Audio-Guide](/guides/audio/).

## Häufige Stolpersteine

| Problem | Lösung |
| ------- | ------ |
| Raum lädt nicht | Browser aktualisieren, WebGL aktivieren, anderen Browser probieren |
| Kein Ton | Mikrofon/Lautsprecher in den Audio-Einstellungen prüfen |
| Mikrofon nicht erlaubt | Browser-Berechtigung für Mikrofon erteilen |
| Andere nicht sichtbar | Raum-Link erneut senden, sicherstellen, dass der Raum geöffnet ist |
