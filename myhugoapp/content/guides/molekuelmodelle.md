# Molekülmodelle & 3D-Objekte in Hubs-Räumen

Chemie ist dreidimensional — genau dafür sind die Hubs-Lernräume da.
Dieser Guide zeigt, wie Sie **3D-Modelle** (z. B. Moleküle) in den Raum
bringen und gemeinsam betrachten.

## Welche Formate werden unterstützt?

Der Raum unterstützt **GLB**-Dateien (das 3D-Format von glTF). Gängige
Quellen:

- **Molekül-Datenbanken:** Exportieren Sie Moleküle als GLB (z. B. aus
  ChemDraw, Avogadro, PubChem 3D-Viewer).
- **Fertige Modelle:** Viele freie 3D-Modell-Plattformen bieten GLB-Downloads.
- **Eigene Modelle:** Erstellen Sie Modelle im Browser-Editor (Spoke) und
  exportieren Sie sie als GLB.

## 3D-Objekt in den Raum einfügen

1. Öffnen Sie das **Medien-Menü** (Plus-Symbol unten in der Mitte).
2. Wählen Sie **"3D-Modell"** (bzw. "Modell").
3. Geben Sie die **URL der GLB-Datei** ein oder laden Sie die Datei hoch.
4. Das Modell erscheint vor Ihnen im Raum.

> **Hinweis:** Nutzen Sie GLB-Dateien von unseren eigenen Ressourcen oder
> aus vertrauenswürdigen Quellen. Modelle von externen Servern können
> blockiert sein, wenn der Server sie nicht freigibt.

## Objekt drehen, skalieren, positionieren

| Aktion | Maus/Touch |
| ------ | ---------- |
| **Auswählen** | Klick auf das Objekt |
| **Drehen** | Rechtsklick (halten) + Maus ziehen |
| **Skalieren** | `Alt` + Linksklick (halten) + Maus ziehen |
| **Bewegen** | Objekt greifen (Klick halten) und ziehen |
| **Kopieren/Löschen** | Objekt-Menü (Klick auf Objekt nach Auswahl) |

## Molekül-Modelle im Unterricht

- **Gemeinsam betrachten:** Stellen Sie das Modell in die Raummitte, alle
  sehen dieselbe Ansicht aus ihrer Perspektive.
- **Rotation zeigen:** Drehen Sie das Modell langsam, während Sie die
  funktionellen Gruppen erklären.
- **Mehrere Modelle vergleichen:** Platzieren Sie z. B. Ethan und Ethen
  nebeneinander, um Bindungsverhältnisse zu vergleichen.

## Tipps & Grenzen

- Große Modelle können das Laden verlangsamen — nutzen Sie komprimierte
  GLB-Dateien.
- Für sehr detaillierte Animationen gibt es Grenzen; statische Modelle
  funktionieren am zuverlässigsten.
- Die gemeinsame Bearbeitung (mehrere Personen gleichzeitig) wird von
  Hubs eingeschränkt — ideal ist: eine Person präsentiert, alle schauen zu.
