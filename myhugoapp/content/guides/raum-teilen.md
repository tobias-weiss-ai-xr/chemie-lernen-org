# Raum teilen & einladen

Damit andere Teilnehmer Ihren Chemieraum auf **hubs.chemie-lernen.org**
betreten können, teilen Sie den Raum-Link. Es gibt mehrere Wege.

## 1. Raum-Link kopieren

1. Klicken Sie unten in der Mitte auf das **Teilen-Symbol** (Pfeil nach oben).
2. Klicken Sie auf **"Link kopieren"**.
3. Senden Sie den Link per E-Mail, Chat, Lernplattform (z. B. Moodle) oder
   Messenger an Ihre Teilnehmer.

Der Link sieht so aus:

```
https://hubs.chemie-lernen.org/iZER9XU/knowledgeable-great-tract
```

> **Wichtig:** Jeder mit dem Link kann den Raum betreten. Teilen Sie ihn
> daher nur an die gewünschte Gruppe.

## 2. QR-Code anzeigen

Im Teilen-Dialog wird auch ein **QR-Code** angezeigt. Damit können
Mobilgeräte den Raum schnell öffnen — praktisch im Klassenzimmer:

- Projektor zeigt den QR-Code
- Lernende scannen ihn mit der Handykamera
- Der Raum öffnet sich direkt im Browser

## 3. Weitere Optionen im Teilen-Dialog

| Option | Funktion |
| ------ | -------- |
| **Link kopieren** | Raum-Link in die Zwischenablage |
| **QR-Code** | Schneller Einstieg per Kamera |
| **Einbetten (Embed)** | Raum in eine eigene Webseite einbetten (z. B. Lernplattform) |
| **Social Media** | Direkt auf Twitter/Facebook teilen |

## 4. Einladung per Lernplattform

Wenn Sie Moodle, Teams oder eine andere Plattform nutzen, fügen Sie den
Raum-Link einfach als **Link-Aktivität** oder **Text-Baustein** ein. Die
Teilnehmer brauchen keinen Account — sie klicken den Link und geben nur
ihren Namen ein.

## 5. Raum für die Klasse vorbereiten

- **Vorab testen:** Betreten Sie den Raum selbst, bevor Sie den Link teilen.
- **Gerne einladen:** Bitten Sie die Teilnehmer, sich kurz vorher
  einzuloggen, damit Namen korrekt angezeigt werden.
- **Raum-Einstellungen:** Im Menü → Einstellungen können Sie z. B. die
  maximale Teilnehmerzahl anpassen.
